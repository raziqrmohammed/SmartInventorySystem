# Smart Inventory Management System

A Python and Streamlit dashboard for monitoring inventory, identifying products that need restocking, estimating monthly demand, and exporting reports.

## Features

- **Dashboard:** View product and category totals, stock levels, and inventory value.
- **Inventory:** Search products, filter by stock status, and sort inventory data.
- **Stock alerts:** Find low-stock and out-of-stock products, with supplier details.
- **Demand forecasting:** Estimate next month’s demand from historical sales data.
- **Business insights:** Review top-selling, slow-moving, and potentially overstocked products.
- **Reports:** Download inventory summaries in CSV or Excel format.
- **Category filter:** Filter dashboard views by product category.

## Built with

- Python
- Streamlit
- pandas
- NumPy
- Plotly
- scikit-learn
- openpyxl (for Excel report exports)
